| Verb       | Prototype                 | Focus                      |
| ---------- | ------------------------- | -------------------------- |
| **be**     | exist in a state          | trạng thái hiện tại        |
| **become** | enter a state             | chuyển sang trạng thái mới |
| **exist**  | have existence            | sự tồn tại                 |
| **remain** | continue despite change   | vẫn còn như cũ             |
| **stay**   | continue in a place/state | ở lại                      |
| **live**   | exist as a living being   | sống                       |
| **seem**   | appear to be (subjective) | có vẻ                      |
| **appear** | become visible / seem     | xuất hiện hoặc có vẻ       |
