| Cách đọc | Khi nào?                             | Ví dụ                       |
| -------- | ------------------------------------ | --------------------------- |
| **/s/**  | Sau âm **vô thanh** (trừ /s, ʃ, tʃ/) | `books`, `cats`             |
| **/z/**  | Sau âm **hữu thanh** và nguyên âm    | `dogs`, `pens`, `plays`     |
| **/ɪz/** | Sau các âm **/s, z, ʃ, ʒ, tʃ, dʒ/**  | `buses`, `watches`, `boxes` |



| Âm cuối | Từ gốc → thêm s | Phát âm đuôi |
| ------- | --------------- | ------------ |
| /p/     | cup → cups      | /s/          |
| /t/     | cat → cats      | /s/          |
| /k/     | book → books    | /s/          |
| /f/     | roof → roofs    | /s/          |
| /θ/     | month → months  | /s/          |

| /b/       | cab → cabs      | /z/          |

| /g/       | dog → dogs      | /z/          |

| /l/       | ball → balls    | /z/          |

| nguyên âm | day → days      | /z/          |
