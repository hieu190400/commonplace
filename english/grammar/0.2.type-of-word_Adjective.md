## Lời mở đầu

Xong Noun (Entity) và Verb (Event), giờ tới Adjective.

## Lý thuyết 

### Adjective

Adjective biểu diễn một Property (thuộc tính). Property là bất cứ đặc điểm nào dùng để mô tả một Entity hoặc một Event.

Ví dụ:

big, small, beautiful, old, happy, difficult, interesting, broken

#### Adjective bình thường (Lexical adjectives)

Là adjective có sẵn trong từ điển.

1. Descriptive adjectives

Thuần là đặc tính: big, small, beautiful, red, old, young, expensive, heavy

2. State adjectives

Mô tả trạng thái: happy, sad, awake, alive, asleep, afraid, ready

3. Relational adjectives

Biểu diễn mối quan hệ: medical, political, economic, wooden, scientific, historical, national.

4. Quantifying adjectives

Biểu diễn lượng, sô lượng: many, few, much, little, some, several, enough

5. Demonstrative adjectives

Chỉ định 1 cái gì đó cụ thể: this, that, these, those

6. Possessive adjectives

Các tính từ sở hưu như: my, your, his, her, its, our, their.

#### Adjective được tạo ra

1. Participial adjectives (V-ing, V3)

Được tạo từ Verb: interesting, interested, boring, bored

2. Compound adjectives

Hai hoặc nhiều từ ghép thành adjective: well-known, good-looking, ten-year-old, high-speed, part-time, 10-minute

3. Deadjectival adjectives (Noun → Adjective)

Một adjective tạo từ adjective khác bằng tiền tố hoặc hậu tố: `happy -> unhappy`, `cloud -> cloudy`, `dirt -> dirty`.

4. Denominal adjectives (Adj → Adj)

Danh từ thành tính từ như trái cam với màu cam: wood → wooden, gold → golden, child → childish, friend → friendly, danger → dangerous

5. Deverbal adjectives (Verb → Adjective bằng hậu tố)

Nó được tạo từ Verb luôn nhưng là tính từ rồi không còn là dạng `Participial adjectives (V-ing, V3)`

Ví dụ: `read -> readable`, `drink -> drinkable`, `help -> helpful`, `lag -> laggy`.

Trường hợp lai vừa là Participial vừa là Deverbal: `interest → interesting/interested`, `excite → exciting/excited`, `tire → tired`.

## Hình thức của Adjective

Siêu ít luôn: chỉ có ở dạng so sánh là nó đổi thôi

### Comparative (So sánh hơn)

1. từ 1 âm tiết
    - Thêm r/er: `big → bigger`, `tall -> taller`, `simple -> simpler`
    - đôi đuôi cho đẹp: `happy -> happier`
2. Từ 2 âm tiết trở lên
    - Thêm more: `beautiful → more beautiful`

### Superlative (So sánh nhất)

1. từ 1 âm tiết
    - Thêm est/st: `big → biggest`, `tall -> tallest`, `simple -> simplest`
    - đôi đuôi cho đẹp: `happy -> happier`
2. Từ 2 âm tiết trở lên
    - Thêm most: `beautiful → most beautiful`

### Tụi ngoại lệ nhức đầu

#### Cấu trúc so sánh

1. Bảng ngoại lệ

| Positive | Comparative     | Superlative       |
| -------- | --------------- | ----------------- |
| good     | better          | best              |
| well     | better          | best              |
| bad      | worse           | worst             |
| far      | farther/further | farthest/furthest |
| little   | less            | least             |
| many     | more            | most              |
| much     | more            | most              |
| old      | older/elder*    | oldest/eldest*    |


2. Một số từ 2 âm tiết dùng cả hai cách

Đều đúng:

clever → cleverer / more clever
common → commoner / more common
gentle → gentler / more gentle
narrow → narrower / more narrow
polite → politer / more polite
quiet → quieter / more quiet
simple → simpler / more simple

Đở nhức đầu thì cứ more/most hết.

#### Ngoại lệ vị trí

Nên nhớ 3 quy tắc này:

- Predicative only(chỉ đứng sau động từ): asleep, afraid, alive, awake...
- Indefinite pronoun + adjective(đứng sau đại từ bất định): something useful, someone special, nothing interesting
- Một số adjective đổi nghĩa theo vị trí: late, present, concerned, responsible



### Mấy cái cần coi.

#### Thứ tự của nhiều adjective

> Opinion → Size → Age → Shape → Color → Origin → Material → Purpose → Noun

Viết tắt: **OSASCOMP**

| Thứ tự | Loại     | Ví dụ                              |
| ------ | -------- | ---------------------------------- |
| 1      | Opinion  | beautiful, nice, ugly, interesting |
| 2      | Size     | big, small, tall, tiny             |
| 3      | Age      | old, young, new, ancient           |
| 4      | Shape    | round, square, long, thin          |
| 5      | Color    | red, black, blue                   |
| 6      | Origin   | Vietnamese, Japanese, French       |
| 7      | Material | wooden, plastic, gold              |
| 8      | Purpose  | sleeping, racing, cooking          |

Nếu 2 từ cùng loại thì đọc sao cho thuận miệng là được.

Mẹo để khỏi học thuộc

Chia thành 3 cụm:

1. Cảm nhận
- Opinion
2. Hình dáng
- Size
- Age
- Shape
- Color
3. Nguồn gốc
- Origin
- Material
- Purpose
- Noun

| Thường gặp         | Ví dụ                 |
| ------------------ | --------------------- |
| Opinion → Size     | a beautiful big house |
| Opinion → Age      | a lovely old man      |
| Size → Color       | a big red car         |
| Age → Color        | an old white dog      |
| Color → Origin     | a black Italian car   |
| Origin → Material  | a Japanese wooden box |
| Material → Purpose | a wooden dining table |
