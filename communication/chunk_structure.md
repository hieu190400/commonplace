# Lý thuyết

## Chunk
Chunk là những cụm từ hoặc mẫu câu được sử dụng như một `đơn vị giao tiếp hoàn chỉnh.`

Ví dụ với Greeting:
```
Hello.
Hi.
Good morning.
What's up?
How's it going?
```

Một chunk có thể là:
```
Một từ: Thanks.
Một cụm từ: Of course.
Một câu: I agree.
Một mẫu có thể thay đổi thành phần: How's + ... + going?
```

## Structure

Là khung câu có thể thay đổi thành phần để tạo ra nhiều câu khác nhau.

I think + [clause]
```
I think he's right.
I think it's a good idea.
I think we should leave.
```

Would you mind + [V-ing]?
```
Would you mind waiting?
Would you mind opening the door?
Would you mind helping me?
```
