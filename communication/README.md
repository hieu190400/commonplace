# Mở đầu

Thư mục này là để học ngôn ngữ một cách có mục tiêu hơn. 

Ngôn ngữ có mục tiêu là để giao tiếp, vì vậy học ngôn ngữ cũng có thể coi là học giao tiếp

Tập trung hết vào nói nha.

# Cấu trúc 

```
FUNCTION
   ↓
TYPES / VARIANTS
   ↓
CHUNK / STRUCTURE
   ↓
RESPONSE
   ↓
TOPIC VOCABULARY
   ↓
GRAMMAR
```

## 1. Function

Bạn muốn làm gì?

Greeting

## 2. Type

Bạn đang làm việc đó trong hoàn cảnh nào?

Formal
Neutral
Casual
Special situation

## 3. Chunk

Câu mẫu bạn cần biến thành phản xạ.

Hello.
Hi.
What's up?

## 4. Response

Người kia thường đáp thế nào?

Hello.
Hi.
Not much.
```
