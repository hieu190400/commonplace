# Lý thuyết


type có thể chia ra thành 4 nhóm lớn.

| Dimension                  | Câu hỏi                  |
| -------------------------- | ------------------------ |
| **Politeness**             | Lịch sự đến mức nào?     |
| **Strength**               | Mức độ mạnh/yếu của ý?   |
| **Directness**             | Nói thẳng hay gián tiếp? |
| **Formality / Register**   | Casual, neutral, formal? |
| **Certainty / Commitment** | Chắc chắn đến mức nào?   |


## Lịch sự - Politeness

| Type                       | Ý nghĩa                             |
| -------------------------- | ----------------------------------- |
| **Blunt / Impolite**       | Thẳng, có thể nghe cộc              |
| **Casual**                 | Tự nhiên, thân mật                  |
| **Neutral**                | Bình thường, không đặc biệt lịch sự |
| **Polite**                 | Lịch sự                             |
| **Very polite**            | Rất lịch sự                         |
| **Formal / Highly polite** | Lịch sự trong bối cảnh trang trọng  |

Ví dụ:

> Give me your phone.

→ Blunt

> Can I use your phone?

→ Neutral

> Could I use your phone?

→ Polite

> Would you mind if I used your phone?

→ Very polite / indirect

## Strength - mức độ mạnh/yếu

Người nói thể hiện mức độ mạnh đến đâu?

Ví dụ

| Level           | Example                |
| --------------- | ---------------------- |
| **Weak**        | I suppose so.          |
| **Mild**        | I think so.            |
| **Normal**      | I agree.               |
| **Strong**      | I definitely agree.    |
| **Very strong** | Absolutely. / Exactly. |

## Directness - độ thẳng 

Nói thẳng hay vòng vo.

| Type              | Example                                                        |
| ----------------- | -------------------------------------------------------------- |
| **Direct**        | Can I leave early?                                             |
| **Indirect**      | Would it be okay if I left early?                              |
| **Very indirect** | I was wondering if it might be possible for me to leave early. |

## Formality / Register - phong cách

Câu này thuộc phong cách nào?

Ví dụ:

| Type            | Example                                |
| --------------- | -------------------------------------- |
| **Very casual** | Wanna come?                            |
| **Casual**      | Do you wanna come?                     |
| **Neutral**     | Do you want to come?                   |
| **Formal**      | Would you like to join us?             |
| **Very formal** | Would you be interested in joining us? |

## Certainty

Độ chắc chắn.

| **Certainty level**      | **Example**                | **Meaning / nuance**                  |
| ------------------------ | -------------------------- | ------------------------------------- |
| **Low**                  | **I think he's right.**    | Tôi nghĩ anh ấy đúng, nhưng chưa chắc |
| **Medium**               | **He's probably right.**   | Khả năng cao là anh ấy đúng           |
| **High**                 | **He's definitely right.** | Chắc chắn anh ấy đúng                 |
| **Very high / Absolute** | **He's absolutely right.** | Hoàn toàn chắc chắn; nhấn mạnh mạnh   |
